# 최신 기능 계약
기존 F01~F10을 모두 구현하고 아래 항목을 합친다. 기존 index의 제외 목록과 충돌하면 이 문서를 우선한다. 변경된 API의 세부 필드는 API 계약과 API-INVENTORY.md를 확인한다.

## 인증과 셸
실제 TOTP, 가입·승인·그룹·메뉴별 View/Write/Admin, 매 요청 서버 권한, 로그인·접근 로그, 최대 12개 탭·복원·다른 탭 닫기, 날씨 샘플 표시를 유지한다.
데모는 명시적 옵션과 독립 DB에서만 관리자/사용자 역할을 전환한다. 이전 토큰 폐기, 메뉴·탭·채팅·모달 상태 초기화가 필요하다. 일반 DB와 일반 계정의 역할 승격은 거부한다. 데모 계정은 admin/han.wk이며 비밀번호는 시연 설정으로 관리한다.

## 호선·간트·실적
호선 CRUD, 마일스톤, 블록, 연계 현황, 공정 진척과 상태 집계를 유지한다. 상세 로딩 중 편집을 방지한다.
호선·간트·도면·공정실적 행의 호버는 실제 상세 API를 사용한다. 지연 오픈, TTL 캐시, 오류·빈 상태, 저장 후 무효화, 늦은 응답 경합, 숨긴 탭과 언마운트 정리를 구현한다.
간트의 날짜 범위, 확대/축소, 드래그 이동/기간 변경, 선후행과 후행 일정 이동, 도면 게이트·지연·휴일 표시는 F05 및 rules 계약을 따른다. 서버에서도 동일 규칙을 검증한다. 지원하지 않는 연도의 공휴일 상태를 표시한다.
공정 실적은 호선→공정 선택→전체 이력→일별 저장/삭제. 호버에는 상태·누적률·최근 3건 날짜/공수/인원. 누적률 역행과 음수 공수는 원래 rules 계약을 보존한다.

## Unity 조선소
실제 Unity WebGL. 목록 아래 전체 폭 반응형 캔버스에 최대 6척씩 배치하고 페이지 이동을 제공한다. 도크/안벽·크레인 트롤리 움직임은 시뮬레이션 표시. 초기 카메라는 현재 선체 전체를 크게 담는다. 우측 시점 버튼 패널은 제거한다.
휠 확대/축소, 드래그 회전/이동, 호버 번호·이름·상태·진척·지연·인도일, 선체 클릭→해당 상세를 구현한다. 페이지 변경에도 hull_no 매핑을 보존한다. 단일 호선 상세 3D 탭도 유지한다.
Unity는 동시에 한 인스턴스. 숨겨진 탭·상세 모달·빠른 열고 닫기·재시도에서 소유권과 자원을 해제한다. 고유 canvas ID, 로더부터 ready까지 전체 timeout, 늦은 인스턴스 종료, WebGL 불가 안내, 로더 실패 재시도를 구현한다. 빌드 파일 배치·MIME도 검증한다.

## 도면·결재·회원
도면 CRUD·리비전·PDF·공정 연결·검토/승인/반려·배포와 도면 게이트를 구현한다. 시연에서만 명시적인 예시 PDF 생성 허용. 원본 첨부를 덮어쓰지 않는다.
회원 승인과 그룹·메뉴별 권한, 관리자/조회자 행동 차이를 유지한다.

## 대시보드·로그·건의문의
모든 대시보드 지표는 DB 집계. 관련 간트/도면 상세 이동과 업무 흐름 매뉴얼 링크를 제공한다.
사용 로그는 사용자·기간·API/화면 집계. 토큰·암호·민감한 본문을 로그에 넣지 않는다. 예시 로그는 DemoYN으로 식별한다.
문의는 BUG/FEATURE/QUESTION/ETC, OPEN/IN_PROGRESS/DONE/REJECTED. 본인 글 조회·작성·허용 상태 수정/삭제, 관리자의 전체 조회·답변 처리, 완료/반려 답변 필수.
챗봇과 문의 화면은 동일 TB_SYS_Inquiry와 서비스 사용. 요청 ID로 중복 방지, 동일 ID 다른 내용은 충돌. 기존 feedback DB는 재실행 가능한 이관. 작성자·시각·기존 접수번호 추적 가능. 열린 문의 탭은 접수 후 갱신한다.

## 로컬 LLM·MCP·보고서
로그인 후 왼쪽 아래 움직이는 배 캐릭터, 인사말 말풍선, 호버 시 말풍선 숨김, 키보드·모바일·움직임 줄이기 설정을 지원한다. 빠른 조회·매뉴얼·건의·문의·보고서 버튼을 제공한다.
Ollama로 일반 질문에 한국어 답변. 기본 참고 모델 qwen2.5:1.5b-instruct. 모델/URL/timeout은 서버 설정. 설치·시작 스크립트, 모델 부재·통신 실패·생성 중·timeout 피드백, 중복 전송 방지와 재시도를 구현한다.
MCP는 실제 initialize→initialized→tools/list·tools/call로 연동한다. 도구는 호선 조회·도면 목록·공정 호선 선택·문의 접수·보고서 생성. 사용자 신원은 인증 세션에서 서버가 주입한다. 입력 검증, 권한, 오류 응답, subprocess timeout·정리, stdout 프로토콜 분리를 갖춘다.
호선 질문→실제 카드→기존 상세. 도면 질문→카드→도면 상세/PDF. 공정실적 질문→호선→공정→실제 최근 실적. 접근 불가 데이터는 모델에도 보내지 않는다. 없는 SN은 사실대로 안내하고 등록 호선을 고르게 한다.
건의/문의는 명시적 접수 모드에서 제출 후 접수번호 표시. 일반 질문을 자동 접수하지 않는다.
보고서는 선택 호선과 권한 있는 데이터로 PDF/XLSX 생성·다운로드. 요약 지표, 호선 목록, 공정 목록, 도면 목록, 선택 호선의 주요 일정 섹션 포함. 생성자 외 접근·경로 탐색 차단, 만료/정리, 한글 폰트, 파일 내용 확인 필수.

## 매뉴얼과 실행
실제 화면 캡처·사용 순서·업무 흐름. 대시보드 단계, 탭 닫기 옆 매뉴얼, 챗봇 질문/버튼으로 관련 항목 열기와 업무 화면 이동을 지원한다.
새 폴더에서 설치·마이그레이션·시드·시연·빌드 가능. 절대 경로·외부 프로젝트 symlink 제거. Unity·Ollama 환경 점검. DB·모델·환경 비밀값·로그는 Git 제외. 캡처는 시연 데이터만 사용. 공개 배포는 별도 사용자 승인 후 진행한다.

## 구현 코드 없이 확인할 추가 계약
간트 드래그로 선행 공정 종료일이 후행 시작일에 닿거나 넘으면 후행 시작일을 모든 선행 종료일의 최댓값+1일로 이동한다. 후행 기간 길이를 보존하고 연쇄 적용하며 순환 관계는 거부한다. 날짜 변경 전체를 한 트랜잭션으로 처리한다.
보고서 KPI는 호선 수·공정 수·지연 공정 수·도면 대기 공정 수·도면 수·미배포 도면 수다. 미배포는 ISSUED/OBSOLETE를 제외한다. 권한 없는 영역은 제외 사실을 표시하고 데이터는 넣지 않는다. 호선 표에는 번호/이름/선종/상태/선주/인도일/진척/지연, 공정 표에는 호선/블록/공정/계획 시작·종료/진척/상태/담당/미배포 필수도면, 도면 표에는 번호/이름/호선/블록/분야/Rev/상태/설계자를 포함한다. 생성자·생성시각·기준일과 상태별 집계를 표시한다.
