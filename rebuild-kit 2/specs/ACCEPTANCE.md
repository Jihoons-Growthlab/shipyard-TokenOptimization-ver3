# 수용 시나리오
각 행에 실제 결과·명령 또는 브라우저 단계·증거 경로·미해결 문제를 기록한다. 시작 상태는 모두 미검증이다.

| ID | 필수 확인 |
| --- | --- |
| A01 | 빈 DB 마이그레이션·시드 및 재실행, 기존 DB 업그레이드·보존 |
| A02 | 가입→승인→로그인, 비활성/대기 거절, TOTP 성공/실패/재사용, 로그아웃 토큰 폐기 |
| A03 | View/Write/Admin별 모든 쓰기 API 직접 호출, 타 사용자 자료 접근 거절 |
| A04 | 탭 열기·중복·복원·닫기·권한 변경 및 폼 로딩 경쟁 |
| A05 | 호선/블록/일정 CRUD, 삭제 연계·진척 집계 |
| A06 | 간트 드래그·기간변경·후행 이동·순환거절·도면 게이트·확대·휴일 |
| A07 | 실적 저장/삭제·누적률/상태 재계산·최근 호버·전체 이력 |
| A08 | 도면 신규·리비전·PDF 검증/업로드/보기/삭제·공정 연결 |
| A09 | 검토→승인→배포→공정 착수 가능, 반려 및 권한 실패 |
| A10 | 회원 승인·그룹/메뉴 권한 수정 후 실제 메뉴/API 적용 |
| A11 | 대시보드 집계·관련 상세·워크플로 매뉴얼 연결 |
| A12 | 사용 로그 기간/사용자/예시 구분, 문의 본인/관리자 조회 및 처리 |
| A13 | Unity 실 WebGL 로딩·다중 선체·양 구역 호버/클릭·휠·크레인·페이지 매핑 |
| A14 | 야드→챗봇 상세→3D→닫기 8회, 숨긴 탭·로딩 중 닫기·실패 재시도·timeout |
| A15 | 390/768/1440px에서 넘침·모달·호버·키보드·움직임 줄이기 |
| A16 | 실제 Ollama 한국어 답변 및 모델/서버 중단·중복 생성·timeout |
| A17 | MCP 초기화·도구 목록·스키마 오류·권한·도면/호선 선택·실적 단계 선택 |
| A18 | 챗봇 건의/문의→화면 즉시 반영·중복 재시도·동일 ID 다른 내용 충돌·기존 2건 이관 |

| A22 | 새 폴더 설치·빌드·시연 실행, 비밀값/실제 DB 제외, 모든 산출물 로딩 |

기본 검증은 backend pytest, frontend vitest, vite build와 Unity build다. 설치된 SDK에 맞춰 명령을 단계 인계에 기록한다. 외부 리소스 부재를 성공으로 취급하지 않는다. 이미지 비교만으로 API와 인터랙션 완료를 판정하지 않는다.
